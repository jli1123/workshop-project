# Completed workshop example

This folder shows approximately what your project should look like after the workshop’s analysis exercise. Use it to compare your code or continue if you get stuck.

The code is complete, but the .venv folder is not included. To create the environment and install the required packages:

1. Open this completed-project folder in VS Code using File > Open Folder.
2. Choose Terminal > New Terminal.
3. Run:

   uv sync

4. Open analysis.ipynb from Explorer.
5. Click Select Kernel and choose this folder’s .venv.
6. Run the notebook cells from top to bottom.


uv must be installed before running these steps. The project configuration is already included, so use uv sync here.
